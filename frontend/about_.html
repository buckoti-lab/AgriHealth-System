ABOUT THE SYSTEM

Project Overview

The Vegetable Disease Detector is an intelligent web-based system designed to help farmers and agricultural experts identify diseases affecting vegetables using deep learning techniques. The system allows users to upload an image of a plant leaf, and it automatically predicts the vegetable type, detects possible diseases, and provides recommended treatments.

Technology Used
  • Backend: Django (Python Web Framework)
  • AI Model: Convolutional Neural Network (CNN)
  • Machine Learning: TensorFlow / Keras
  • Database: MySQL
  • Frontend: HTML, CSS, JavaScript, Bootstrap
  • Image Processing: OpenCV, Pillow
Objectives
  • To assist farmers in early detection of plant diseases
  • To reduce crop losses through early intervention
  • To provide fast and accurate disease classification
  • To integrate AI into practical agricultural solutions
How It Works
  1. User uploads a vegetable leaf image
  2. The system preprocesses the image
  3. The trained AI model analyzes the image
  4. The system predicts vegetable type and disease
  5. Recommended treatments are displayed
Project Scope

This system is developed as a Final Year Project (FYP) by a group of five students under the supervision of academic staff. It demonstrates the application of artificial intelligence in agriculture and aims to support smart farming practices.

Future Improvements
  • Mobile application integration
  • Real-time field disease detection
  • Support for more crop types
  • Improved AI accuracy with larger datasets
